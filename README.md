# 网际快车（wj-kc.com）青龙自动签到脚本

## 功能

- 自动签到获取每日流量奖励
- 支持账号密码登录（自动 MD5 加密）
- 支持 Cookie 登录
- 多账号支持
- 签到记录查询
- 累计获得流量统计
- 青龙通知推送

## 环境变量

### 方式一：账号密码（推荐）

```
WJKC_ACCOUNT=邮箱&密码
```

多账号换行：

```
WJKC_ACCOUNT=邮箱1&密码1
邮箱2&密码2
```

### 方式二：Cookie

```
WJKC_COOKIE=token=xxx
```

### 可选配置

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `WJKC_URL` | 站点地址 | `https://0n.wj-kc.com` |
| `WJKC_TIMEOUT` | 请求超时(ms) | `15000` |

## 部署到青龙面板

### 1. 添加脚本

将 `wjkc_sign.js` 复制到青龙面板 `/ql/scripts/` 目录。

### 2. 添加环境变量

在青龙面板 → 环境变量 中添加：

```
名称：WJKC_ACCOUNT
值：账号邮箱&密码
```

### 3. 添加定时任务

在青龙面板 → 定时任务 中添加：

| 字段 | 值 |
|------|-----|
| 名称 | 网际快车签到 |
| 命令 | `task wjkc_sign.js` |
| 定时规则 | `17 8 * * *` |
